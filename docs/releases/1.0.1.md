# Daily Note Key 1.0.1

Open one fixed, selected note using an Obsidian hotkey or ribbon icon.

- Select a Markdown note from the vault using the file picker.
- Assign a shortcut to **Daily Note Key: Open today note** in Hotkeys settings.
- Use the calendar ribbon icon for the same opening action.
- A red warning triangle indicates an unconfigured or missing note.

The plugin does not create or modify notes and uses no network or telemetry.
It is distributed under the MIT licence.

## Installation

Place the attached `main.js`, `manifest.json`, and `styles.css` together in
`<vault>/.obsidian/plugins/today-note-custom-hotkey/`, reload Obsidian, and
enable **Daily Note Key** in Community plugins settings.

Existing local users of `daily-note-key-plugin` should disable that installation,
enable the new one, and select the note and hotkey again. Existing settings are
not automatically migrated or deleted.

Community-directory submission is pending. The manifest permits mobile use;
the declared minimum Obsidian version remains to be established through
version-specific compatibility testing.
